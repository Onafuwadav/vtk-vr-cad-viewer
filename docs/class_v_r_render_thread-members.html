This project implements a 3D CAD viewer using Qt and VTK, aimed at visualizing and manipulating 3D models. It provides basic functionalities such as loading STL files, applying rotation, and using filters like clipping and shrinking on the models. The user can interact with the models through a GUI interface, and advanced features such as VR support have been integrated to demonstrate a more immersive experience.
